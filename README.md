# itsm-ml-project

ITSM machine learning project: priority prediction, incident volume forecasting, NLP auto-tagging, RFC prediction



46,606 tickets closed 1 Oct 2013 to 31 Mar 2014.” Never say “three years of data”



\# ITSM incident analytics (work in progress)



Machine learning on IT service-management tickets, in four tracks: (1) flag likely high-priority tickets, (2) forecast ticket volume, (3) tag tickets, (4) predict change requests.



Status: Track 1 modelled; Tracks 2 to 4 planned. Final results, figures and run instructions will be added when the project is complete.



The dataset is confidential and not included. Credentials are never committed (see `.env.example`).
